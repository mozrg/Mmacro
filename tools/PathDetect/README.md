# PathDetect

Инструмент для TDS: показывает красную дорожку (путь мобов) поверх игры и сетку точек
«можно/нельзя ставить». Работает на AutoHotkey v1.1 + PowerShell (встроен в Windows).

## Запуск

1. Открой `PathDetect.ahk` (двойной клик).
2. **F4** — обвести игровое поле (сохранится в `PathDetect.ini`).
3. **F9** — показать окно, нажать **6** (выбор юнита) и увести курсор в левый верхний угол окна Roblox.
   **F10** — закрыть, **F11** — перезапустить, **F12** — выход.

## В окне

- **ЛКМ** — проверить точку: дорожка или свободно;
- **F5** — новый снимок;
- **F6 / F7** — чувствительность к красному;
- **S** — настройки (шаги/радиусы точек, кайма, зоны HUD);
- **D** — скрыть/показать сетку;
- **Esc** — выход.

Настройки сохраняются в `PathDetect.settings.txt` рядом со скриптом.

## Расстановка юнитов

**F8** — расставить юнитов по углам квадрата вокруг курсора:

- курсор — это левый верхний угол квадрата, клики идут по часовой стрелке;
- радиус квадрата (от центра до угла) = шаг сетки / N, по умолчанию N = 3, т.е. 1/3 шага;
- между кликами пауза 100 мс;
- окно детектора на время кликов прячется, чтобы клики шли в игру.

Всё настраивается в трее: **Настройки расстановки** — клавиша выбора юнита (жмётся после F9),
делитель радиуса, пауза, число углов (1–4), прятать ли окно. Хранится в `PathDetect.ini`,
секция `[Place]`.
