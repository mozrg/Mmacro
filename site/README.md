# Сайт Mmacro

Статический сайт без сборки и npm. Все файлы лежат в этой папке.

## Локальный просмотр

Из корня репозитория:

```powershell
python -m http.server 4173 --directory site
```

Открыть `http://127.0.0.1:4173/`. Файлы также работают при открытии `index.html` напрямую, но локальный сервер ближе к реальному хостингу.

## Структура

- `index.html` — главная страница;
- `versions.html` — история всех опубликованных релизов;
- `styles.css` — дизайн-система и адаптивная вёрстка;
- `app.js` — меню, загрузка данных версий, форматирование заметок;
- `data/releases.js` — проверенный снимок релизов для случая, когда GitHub API недоступен;
- `assets/` — логотипы, favicon, OG-изображение, локальные шрифты и их лицензии.

## Версии и скачивание

Основная кнопка ведёт прямо на архив тега:

```text
https://github.com/mozrg/Mmacro/archive/refs/tags/<версия>.zip
```

При загрузке страница дополнительно запрашивает GitHub Releases API. Если у нового релиза появится прикреплённый ZIP-ассет, он будет выбран автоматически. Если API недоступен или сайт открыт через `file://`, используется снимок из `data/releases.js`.

## Шрифты

- Unbounded — SIL Open Font License, файл `assets/licenses/OFL-Unbounded.txt`;
- Golos Text — SIL Open Font License, файл `assets/licenses/OFL-Golos-Text.txt`.

Шрифты хранятся локально; внешние запросы к Google Fonts не выполняются.

## Публикация

Содержимое `site/` можно раздавать как корень любого статического хостинга. Для GitHub Pages нужен отдельный workflow: стандартная настройка Pages не умеет публиковать произвольную папку `site/`.
